# automon

Автоматическая настройка мониторинга сервера в изолированной среде

## Сеть

Проект по стандарту занимает порт:
- localhost:3000 - grafana

Порт grafana доступен только на localhost, потому что так прописано в compose.yaml, поэтому из интернета к нему не подключиться, нужно прокидывать порты: `ssh -N -L 8000:127.0.0.1:{порт grafana} {user}@{ip}` - панель управления grafana будет доступна на локальном устройстве на порту 8000

Compose создает виртуальную сеть на 172.30.0.0/24, через которую все контейнеры общаются

Порт node-exporter открывается на хосте на интерфейсе сетевого моста docker, потому что network_mode: host и --web.listen-address=172.30.0.1:${NODE_PORT}
